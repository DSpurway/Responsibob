Top 3 Improvements
  • High
    Switch to pre-built Ollama binary. Eliminates 10–15 min compile, removes PyTorch venv (~2GB), removes pinned commit. Proxy and UI unchanged — same OpenAI-compatible endpoint.
  • High
    Enable stream: true in the UI. extraction.js already has the correct code with commented-out onToken callback. Reduces peak RAM pressure, gives user progressive feedback.
  • Medium
    Remove debug logging from proxy. Gate console.log(headers) behind process.env.DEBUG. Change logLevel:'debug' to logLevel:'warn'.
